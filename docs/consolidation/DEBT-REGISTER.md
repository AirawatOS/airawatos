## Top-ten risks (severity-ranked)

1. **Unauthenticated privileged reference endpoints** — filestore (any blob r/w), notify (forge any inbox item), scheduler `/run` (execute any installed component in any tenant via the passwordless platform-service principal), model_gateway (`/complete|/embed|/transcribe` spend money), automation/event_relay. [DEBT-B5]
2. **Fail-OPEN internal-token gates; `RUNTIME_MANAGER_INTERNAL` set in no deploy file** — secrets `/materialize` (raw secrets) + `/fetch` (secret-injecting egress proxy) and runtime-manager `/invoke` (Docker + secret materialize) skip the gate when the env is unset. [DEBT-B4, DEBT-A36]
3. **Authority derived from token role claims, pervasively** — kernel/network/app-host/identity/reference; identity stamps `roles` into the token and downstream enforces off it; revocation ineffective for the 1h token life. The single most cross-cutting violation. [DEBT-B1]
4. **`is_platform_authority` = tenant name (+ prod default `airawat`)** — network-wide super-authority from a tenant name, not a recorded grant; also the first-steward chicken-and-egg. [DEBT-B2, DEBT-A17; ADR-0122 target]
