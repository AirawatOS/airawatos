Welfare Gap → Funded Project → Outcome

One run of the whole federated loop — a ministry publishes a programme, a city finds who's below the dignity floor, turns it into a funded project, delivers it, and proves the result — each step in a named tenant and app. Grounded on the live Kanpur crowding project.

Release a tranche — gated

Hit Release. The gate checks: an active subscription (step 5) and a verified milestone VC (step 8), read across the tenant boundary. If both hold → the tranche disburses in MoHUA's own ledger. Revoke the subscription and it refuses. Do the same as HUDD.

produces finance.transaction (funder disbursement) · award released
